# LabFS

一个演示的文件系统，可用于学习文件系统的原理。
因 Windows 打开磁盘为 RAW 过于难且 AI 不擅长 Windows，所以打开磁盘为 RAW 不支持在 Windows 上使用。
Windows 可使用 .img 文件模拟 RAW盘。

索引中的每个路径由 `type` 区分类型：`dir` 是目录，`file` 或省略
`type` 是文件（省略形式用于兼容旧索引）。新索引默认包含不可删除的根目录 `/`。

所有路径都必须从 `/` 开始，允许末尾带 `/`，但不能包含连续的 `/`、`.` 或
`..` 路径段。创建文件或目录前，其父目录必须已经存在；目录仅能在为空时删除。
